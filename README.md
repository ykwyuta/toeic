# TOEIC L&R 模擬試験制作

Claude Code、Antigravity、Muse、Codexで共同執筆するための [執筆・検品ガイド](AGENTS.md) と、Cloudflare Pages向け静的サイトの試作です。試作はPart 5のオリジナル3問で、履歴の保存・移行を確認できます。

## Wranglerで開発・公開

リポジトリのルートから、Node.jsとnpmで次のコマンドを実行します。Wrangler 4が `dist` 内の静的ファイルを配信します。

```sh
npx wrangler@4 pages dev dist --port 8788
```

Cloudflare Pagesの公開はDirect Uploadを使います。初回のみWranglerにログインし、対象アカウントと既存のPagesプロジェクトを確認します。

```sh
npx wrangler@4 login
npx wrangler@4 whoami
npx wrangler@4 pages project list
```

対象プロジェクトがまだない場合は作成します。以下ではプロジェクト名を `toeic`、本番ブランチを `master` としています。既存のプロジェクトを使う場合は、実際の名前と本番ブランチを指定します。

```sh
npx wrangler@4 pages project create toeic --production-branch master
```

初回の作成後も、更新時も、リポジトリの本番に出す内容で次を実行します。

```sh
npx wrangler@4 pages deploy dist --project-name toeic --branch master
```

Wranglerが表示するURLで、解答、再読み込み、履歴の書き出し・復元、オフライン利用を確認します。CIで実行する場合は、Cloudflare Pagesの編集権限を持つAPIトークンを `CLOUDFLARE_API_TOKEN`、対象アカウントIDを `CLOUDFLARE_ACCOUNT_ID` としてCIのシークレットに設定します。[Cloudflare Pages Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/) [CIでのDirect Upload](https://developers.cloudflare.com/pages/how-to/use-direct-upload-with-continuous-integration/)

ブラウザ内の履歴はオリジン単位で保存されます。履歴のJSONをダウンロードし、別端末や公開ドメインへの切替後に読み込めます。同じ受験IDを重複登録せず、不正なデータは保存前に拒否します。サイトは履歴送信用のAPI、アカウント、分析タグを使用しません。

## フル模試への拡張

版付き問題データと事前生成した画像・音声を静的アセットとして配信します。200問セットを追加する段階では、受験中の回答と再開位置をIndexedDBに保存し、履歴書き出しには試験ID・版・受験ID・開始/終了時刻・回答・採点結果を含めます。JSONの版移行、新旧の試験版の共存、インポートの一括保存を検証します。

本番モードはリスニング約45分とリーディング75分の時間制御を持ち、解説・音声台本は提出後に表示します。リスニング素材は事前に読み込み、端末の音声再生に必要な最初の操作を案内します。静的公開では問題データを取得できるため、本番モードの解説制御は学習体験のためのものです。Pagesの1ファイル25 MiB制約に合わせ、長い音声は区間で分割します。[Cloudflare Pages 制限](https://developers.cloudflare.com/pages/platform/limits/)

## オフライン利用とキャッシュのリセット

HTTPSの公開URL、またはローカルの `http://localhost:8788/` をオンラインで一度開き、「オフラインで利用できます。」が表示されるまで待ちます。その後は通信を切ってページを開き直しても、問題・採点・解説・履歴を利用できます。履歴のJSON出力と読み込みも端末内で動作します。

「キャッシュを再取得」は、このサイトのService Workerキャッシュを消し、ブラウザのHTTPキャッシュを使わずにページを取得します。学習履歴はブラウザ内に残ります。オフライン中に実行すると削除のみが完了する場合があるため、ページを閉じる前に再接続して同じ操作を実行してください。

配信内容を変更する際は `dist/sw.js` のキャッシュ版を更新します。音声・画像を含む模試を追加する際は、試験IDと版ごとに必要素材の一覧を持ち、全素材の保存後にオフライン準備完了を表示します。音声の区間再生も通信を切って検証します。

## 苦手分析・単語帳・学習パートナー

苦手分析は技能別に正答数と回答数を表示します。3回答以上かつ正答率70%未満の技能があれば、正答率が最低の技能を復習候補として表示します。試作では同じ3問の再受験も集計するため、表示は復習の目安です。

単語帳には自分で単語を入力するか、採点後の解説から登録できます。単語を開くと意味が表示され、習得済みの状態を切り替えられます。学習履歴と単語帳は同じJSONで持ち運べます。以前の履歴のみのJSONも読み込め、同じ受験IDや登録済みの単語は重複しません。

学習パートナーは、ひなた・蓮・ミロから選べます。採点に応じてお祝いまたは励ましの表情に変わります。キャラクター画像もオフライン用に保存されます。

## 初回の流れと学習メニュー

初回は学習パートナーを選び、文法・語彙6問のチェックを受けます。技能ごとの結果をもとに、分野学習の開始候補を表示します。再訪時は学習メニューを開き、設定から再チェックできます。診断結果とパートナーの選択はこのブラウザに保存されます。

- 分野学習では技能ごとの問題を解き、苦手分析と単語帳を確認できます。
- 模擬試験ではPart 5のミニ模試3問を解きます。この結果を履歴と苦手分析に反映します。
- 設定ではパートナー変更、再チェック、学習履歴、バックアップ、オフライン設定を扱います。

英語力チェックは文法・語彙の復習方針を決めるための簡易診断です。公式スコアへの換算は行いません。

診断・分野学習・模擬試験の解答後に、問題文の日本語訳、全選択肢の個別解説、単語・熟語一覧を確認できます。
