# 分野学習の問題

試験IDは `field-study-01`、現行版は2です。Part 1〜7の29分野に各10問、計290問を収録しています。第1版の29問、既存教材から分野に合わせて選んだ210問、新作51問です。

| Part | 分野 |
| --- | --- |
| 1 写真描写 | 動作、状態、位置関係 |
| 2 応答 | 疑問詞への応答、Yes・No疑問文、依頼・提案への応答、間接応答 |
| 3 会話 | 目的・場面、詳細、次の行動、発言の意図、図表照合 |
| 4 説明文 | 目的・場面、詳細、次の行動、発言の意図、図表照合 |
| 5 短文穴埋め | 品詞、動詞の形、接続詞と前置詞、語彙と文脈 |
| 6 長文穴埋め | 語句補充、文脈・つながり、文挿入 |
| 7 読解 | 目的・要旨、詳細、推論、複数文書照合、文挿入 |

`listening12.txt`、`listening34.txt`、`reading.txt` が第1版、`new-photos.txt`、`new-listening.txt`、`new-reading.txt` が第2版の追加原稿です。`reuse.json` に既存教材から採用した問題番号を収録し、配信データの `source` に元のIDを記録しています。第1版の29問は `fs1-` のIDと内容を維持し、追加分には `fs2-` のIDを付けました。

原稿は `@` でセットが始まり、`*` または `&` が写真情報、`:` が本文・台本、`#` と `=` が図表、`?` が設問、`A`〜`D` が選択肢、`!` が正答、`%` が語彙を示します。フィールドの区切りには `|`、表のセルの区切りには `;` を使います。

第2版では執筆後に正答と解説を伏せて290問を独立解答し、修正・差し替え後の問題を再解答しました。最終版との一致は [独立解答記録](review-r2.txt) を参照してください。難度は編集上の仮説です。

追加した写真6枚は組み込みのCodex ImageGenで作成し、スマートフォン相当の幅で全選択肢と照合しました。写真は `dist/study/r2/photos`、最終生成プロンプトと参照先は [photo-assets.json](photo-assets.json) にあります。Part 1〜4は計170本の音声を収録し、追加した音声はリスニング模試と同じKokoroの米語・英語ボイスで合成しました。2名による音声評価は今後の検品項目です。

音声170本のデコード、長さ、ピークを検査し、新作と抽出分の43本を台本と照合しました。

モバイル幅のChromiumで、全29分野の選択、290問の表示、前後移動、採点後の履歴からの再表示、オフラインでの写真と音声の利用を確認しました。

原稿を更新する場合は、[リスニング模試の音声生成手順](../listening-src/README.md)で指定した同じモデルとライブラリを使います。

```powershell
python study-src/build.py --model-dir .listening-build/model --check
```

現行の配信データと追加音声は `dist/study/r2`、WAVマスターは `.listening-build/study` に出力します。配信データ、音声、写真の検査だけを行う場合は `python study-src/build.py --check` を実行します。
