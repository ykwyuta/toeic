試験IDは `field-study-01`、現行版は3です。Part 1〜7の29分野に各19問、計551問を収録しています。第2版の290問に各分野9問を加えました。追加261問の内訳は新作163問と、既存教材から選んで分野学習用に整えた98問です。

`listening12.txt`、`listening34.txt`、`reading.txt` が第1版、`new-photos.txt`、`new-listening.txt`、`new-reading.txt` が第2版の追加原稿です。第3版の追加原稿は `r3-photos.txt`、`r3-replies.txt`、`r3-listening.series`、`r3-reading.txt`、`r3-reading.series` です。既存教材から採用した問題番号は第2版が `reuse.json`、第3版が `reuse-r3.json` にあり、配信データの `source` に元の問題IDを記録しています。第3版の追加分には `fs3-` のIDを付け、第2版までの問題データを引き継いでいます。

原稿は `@` でセットが始まり、`*` または `&` が写真情報、`:` が本文・台本、`#` と `=` が図表、`?` が設問、`A`〜`D` が選択肢、`!` が正答、`%` が語彙を示します。フィールドの区切りには `|`、表のセルの区切りには `;` を使います。`.series` では `@` の直後に共通素材を定義し、`>` ごとに1問を作ります。`common` は共通の本文・台本、`table` は図表も表示、`linked` は `&:` の文書も表示、`local` は該当問題の素材を使います。

第3版の追加261問は、正答・解説を伏せた原稿で独立解答しました。修正・差し替えた21問を再解答し、全問の正答が一致しました。第2版の290問は既存の配信データと照合しました。難度は編集上の仮説です。[第3版の独立解答記録](review-r3.txt)・[第2版の独立解答記録](review-r2.txt)

配信中の写真24枚のうち、第3版で追加した9枚はCodex ImageGenで生成し、スマートフォン相当の幅で全選択肢と照合しました。追加写真は `dist/study/r3/photos` にあります。最終生成プロンプトと参照先は版ごとの台帳に記録しています。[第3版の写真台帳](r3-photo-assets.json)・[第2版の写真台帳](photo-assets.json)

Part 1〜4は323本のMP3を収録しています。追加153本はリスニング模試と同じKokoroの米語・英語ボイスで合成しました。全323本のデコード・長さ・ピークを検査し、追加分の77本を自動文字起こしで台本と照合しました。2名による音声評価は未実施です。

モバイル幅のChromiumで、全29分野の選択、551問の表示、前後移動、採点後の履歴からの再表示、オフラインでの写真と音声の利用を確認しました。

