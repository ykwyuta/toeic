# 分野学習の問題

試験IDは `field-study-01`、現行版は4です。Part 1〜7の29分野に各24問、計696問を収録しています。第3版の551問に各分野5問ずつ加えました。追加145問の内訳は新作105問と、既存教材から選んで分野学習用に整えた40問です。

| Part | 分野 |
| --- | --- |
| 1 写真描写 | 動作、状態、位置関係 |
| 2 応答 | 疑問詞への応答、Yes・No疑問文、依頼・提案への応答、間接応答 |

| 6 長文穴埋め | 語句補充、文脈・つながり、文挿入 |

`listening12.txt`、`listening34.txt`、`reading.txt` が第1版、`new-photos.txt`、`new-listening.txt`、`new-reading.txt` が第2版の追加原稿です。第3版と第4版の追加原稿は、版番号を付けた `r3-*.txt`、`r3-*.series`、`r4-*.txt`、`r4-*.series` にあります。採用元の問題番号は `reuse.json`、`reuse-r3.json`、`reuse-r4.json`、採用元の問題IDは配信データの `source` に記録しています。第4版の追加分には `fs4-` のIDを付け、既存551問の問題IDとデータを引き継いでいます。

原稿は `@` でセットが始まり、`*` または `&` が写真情報、`:` が本文・台本、`#` と `=` が図表、`?` が設問、`A`〜`D` が選択肢、`!` が正答、`%` が語彙を示します。フィールドの区切りには `|`、表のセルの区切りには `;` を使います。`.series` では `@` の直後に共通素材を定義し、`>` ごとに1問を作ります。`common` は共通の本文・台本、`table` は図表も表示、`linked` は `&:` の文書も表示、`local` は該当問題の素材を使います。

第4版の追加145問は、正答・解説を伏せた原稿で独立解答しました。修正・差し替えた32問を再解答し、全問の正答が一致しました。第3版の551問は既存の配信データと照合しました。難度は編集上の仮説です。[第4版の独立解答記録](review-r4.txt)・[第3版の独立解答記録](review-r3.txt)・[第2版の独立解答記録](review-r2.txt)

配信中の写真29枚のうち、第4版で追加した5枚は組み込みのCodex ImageGenで生成しました。追加写真は `dist/study/r4/photos` に保存し、各写真の動作・状態・位置関係の全選択肢を照合しました。最終生成プロンプトと参照先は版ごとの台帳に記録しています。[第4版の写真台帳](r4-photo-assets.json)・[第3版の写真台帳](r3-photo-assets.json)・[第2版の写真台帳](photo-assets.json)

Part 1〜4は408本のMP3を収録しています。第4版の追加85本はリスニング模試と同じKokoroの米語・英語ボイスで合成しました。全408本のデコード・長さ・ピークを検査し、追加分の51本を自動文字起こしで台本と照合しました。2名による音声評価は未実施です。

モバイル幅のChromiumで、全29分野の選択、696問の表示、前後移動、採点後の履歴からの再表示、オフラインでの写真と音声の利用を確認しました。

原稿を更新する場合は、[リスニング模試の音声生成手順](../listening-src/README.md)で指定した同じモデルとライブラリを使います。

```powershell
python study-src/build.py --model-dir .listening-build/model --check
```

現行の配信データと追加音声は `dist/study/r4`、WAVマスターは `.listening-build/study` に出力します。ビルドでは第3版の配信データを読み込み、追加問題と素材を組み込みます。配信データ、音声、写真の検査だけを行う場合は `python study-src/build.py --check` を実行します。
