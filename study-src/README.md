# 分野学習の問題

試験IDは `field-study-01`、版は1です。分野学習のためにPart 1〜7から29分野を選び、全分野にオリジナル問題を1問ずつ収録しました。

| Part | 分野 |
| --- | --- |
| 1 写真描写 | 動作、状態、位置関係 |
| 2 応答 | 疑問詞への応答、Yes・No疑問文、依頼・提案への応答、間接応答 |
| 3 会話 | 目的・場面、詳細、次の行動、発言の意図、図表照合 |
| 4 説明文 | 目的・場面、詳細、次の行動、発言の意図、図表照合 |
| 5 短文穴埋め | 品詞、動詞の形、接続詞と前置詞、語彙と文脈 |
| 6 長文穴埋め | 語句補充、文脈・つながり、文挿入 |
| 7 読解 | 目的・要旨、詳細、推論、複数文書照合、文挿入 |

`listening12.txt`、`listening34.txt`、`reading.txt` が編集原稿です。`@` でセットが始まり、`*` が写真情報、`:` が本文・台本、`#` と `=` が図表、`?` が設問、`A`〜`D` が選択肢、`!` が正答、`%` が語彙を示します。フィールドの区切りには `|`、表のセルの区切りには `;` を使います。問題IDは各セットの識別子に `fs1-` を付けたものです。

執筆後、正答・解説を伏せた29問を独立解答し、正答表との一致を確認しました。設問の表現を調整した3問は再解答しました。難度は編集上の仮説です。

Part 1の写真3枚は組み込みのCodex ImageGenで作成し、スマートフォン相当の幅で選択肢と照合しました。写真は `dist/study/r1/photos`、最終生成プロンプトは `listening12.txt` にあります。Part 1〜4の音声は、リスニング模試と同じKokoroの米語・英語ボイスで合成しています。2名による音声評価は今後の検品項目です。

音声17本をデコードして台本と照合しました。モバイル幅のChromiumで全29問の採点・解説、単語帳への登録、既存のPart 5ミニ模試、オフラインでの写真表示・音声再生・音声の途中への移動を確認しました。

原稿を更新する場合は、[リスニング模試の音声生成手順](../listening-src/README.md)で指定した同じモデルとライブラリを使います。

```powershell
python study-src/build.py --model-dir .listening-build/model --check
```

配信データと音声は `dist/study/r1`、WAVマスターは `.listening-build/study` に出力します。配信データ、音声、写真の検査だけを行う場合は `python study-src/build.py --check` を実行します。
